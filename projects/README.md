# Master prototype

**master-prototype.html** — This prototype has onboarding two types and viewing course content two types — all created before Aug 30.

It is a single self-contained HTML file covering:

- **Onboarding, two types** — conversational ("Talk it through") and the guided form ("Fill out a quick form")
- **Course content, two types** — Learn with Rubi and Classic course view
- Plus login, dashboard, and flashcards; white surfaces; a resizable Rubi panel; and the reading text-selection menu.

Open `master-prototype.html` in any modern browser.
